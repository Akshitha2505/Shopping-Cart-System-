Shopping Cart System
📌 **Project Description**

The Shopping Cart System is a Python mini project developed using user-defined functions. 
It allows users to view products, add items to the shopping cart, calculate the total price, and manage their orders.
This project is designed to demonstrate basic Python programming concepts such as
functions, dictionaries, lists, loops, conditional statements, and user input.

**🎯 Features**
User login
Display available products
Add products to cart
Update product quantity
Remove products from cart
View shopping cart
Calculate total price
Apply discounts
Place orders
View order history
Exit the application
**🛠️ Technologies Used**
Python
Functions
Lists
Dictionaries
Loops
Conditional Statements
